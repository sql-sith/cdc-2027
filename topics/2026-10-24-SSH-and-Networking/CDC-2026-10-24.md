## Build the VM

1. Click the Create VM button
2. On the General tab, set the following values and then click Next:

- Resource Pool: School-14
- Name: [firstname]-[OS]-[index]

  - Examples:
  - chris-ubuntu-01
  - chris-ubuntu-02
  - chris-windows-01

3. On the OS tab, set the following values and then click Next:

- Use CD/DVD disk image file (iso)
- Storage: ISOs
- ISO image: ubuntu-24.04.3-desktop-amd64.iso
  - Type: Linux
  - Version: 6.x – 2.6 Kernel

4. On the System tab, set the following values and then click Next:

- Graphic card: VirtIO-SPICE <<---- this is a change
- Leave all others at their default values

5. On the Disks tab, set the following values and then click Next:

- SSD Emulation
- Discard
- Leave all others at their default values

6. On the CPU tab, set the following values and then click Next:

- Sockets: 1
- Cores: 4
- Type: host
- Leave all others at their default values

8. Don't make any changes on the Network tab. Just click Next.

9. On the Confirm tab, make sure that all the choices listed there match these instructions. When you are satisfied that they do, click Finish, and job will be scheduled to build your VM.

## Post-install Instructions

## Network Connectivity

- /24 is what I put into Network Mask last week
- The GUI does not understand this and gives you a /0 instead
  - This means that your IP has no network section (Network Mast is 0) and the entire address is your host IP
  - This, in turn, means that nothing is on the same "network" as you
  - Which, finally, means that packet routing is problematic
- The solution, when useing the GUI network config
  - Use 24 (without the slash). The GUI understands this.
  - Alternatively, use 255.255.255.0. This may be preferable, since it "feels right" as a fallback from the /24 "CIDR" IP.

## Network Setup

### IPv4 Network Settings (in settings gui)

- proxy: http://199.100.16.100:3128
- gateway: 144.76.90.254
- your ip: 144.76.90.[Proxmox VM ID]/24
- network mask: 255.255.255.0

### Set /etc/apt/apt.conf's contents to the following:

Acquire::http::Proxy "http://199.100.16.100:3128";
Acquire::https::Proxy "http://199.100.16.100:3128";
