# Cedar Rapids Area Homeschools

## IT Club Cyber Defense, 2026-2027 season

This repository holds meeting notes, source code, and other resources for our club. Here's a quick guide for where things belong:

Need a link? Go to [cdc2027.com](http://cdc2027.com). It has links to the following sites.

* This GitHub repository
* The online interface for Our Zulip server
* Iowa State's Discord site
* Our YouTube recordings
* Proxmox
* Our MS Teams meeting

## Here are a few comments about each of the resources I just mentioned

### Zulip

Our main chat and coordination hub.

**✅ Action:** Install Zulip on your phone or laptop and turn on notifications. Sometimes we put messages on Zulip that are urgent, so we need you to get those notifications quickly.

### Proxmox

Virtual machine platforms hosted by Iowa State — basically the Internet in a bottle.

### Discord

Iowa State runs a Discord server where you can ask questions or chat with **Innovate IT** staff and other students. You can join without an invitation. The #cyberdefense channel is the one to join.

### Teams

We use Microsoft Teams for meetings when Chris is available. Recordings go to YouTube, and any class materials (including AI-generated notes) get posted here under `/topics`.

### YouTube

Our YouTube channel hosts meeting recordings. They're unedited - faster to post, easier to search. YouTube auto-generates transcripts.

If you want to jump to a specific section, open the transcript and search for keywords. When you click the transcript, you will jump straight to that part of the video.
